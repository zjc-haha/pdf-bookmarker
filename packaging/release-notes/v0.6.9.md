PDF 书签工具 0.6.9 正式版（Windows 免安装版）。下载 `PDFBookmarker-Windows-Portable-0.6.9.zip`，完整解压后打开 `PDF书签工具` 文件夹，运行 `PDF书签工具.exe`。请保留整个文件夹，不要在压缩包内直接运行。

## 相对 0.6.8 的主要变化

**书签质量**
- 书签层级按印刷目录的缩进确定：章内与小节同样缩进的“附录 1.1”等归入所在章，与章同级的“附录 A”仍为顶层；“绪论”等没有章号的标题下缩进的 `0.1`、`0.2` 归入该标题。
- 目录跨页时，续页若从一章中间开始、页上没有章标题，识别出的层级可能整体偏浅，现在会依据前几页同样编号层数的层级校正回来。
- 所有书签最前面增加一条指向目录页的书签：中文书为“目录”，其他书为“Contents”。核对旧书签时不计入这条书签，原书签一致的 PDF 不会为补它而改写。
- 写出 PDF 时保留原书的页码标签（如 i、ii、1、2）、页面版式、语言和阅读器设置，写出后校验页码标签一致。

**界面**
- 标签页、下拉框、表格和滚动条改为扁平样式，复选框和单选框改为圆角图标，中文提示按字符换行；图标使用 Tabler Icons。
- “处理设置”并入运行范围信息栏，设置窗口分为 API Key、处理规则、运行方式三组，每个选项附有说明。
- 左侧列出找到的全部 PDF，包括预计跳过和无法读取的文件；筛选或选中只改变显示，整批处理仍检查整个来源文件夹。

**数据与安全**
- 报告、识别缓存、临时数据和加密的 API Key 统一保存在程序目录 `data/`，输出目录只放生成的书签 PDF；旧位置的密钥和报告会自动迁移。清空 API Key 输入框不会删除已保存的密钥。
- 跨盘直接覆盖原 PDF 时先在程序目录备份并记录，写回校验失败会自动恢复；意外中断后，下次启动会检查并恢复。
- pdfminer 无法解析的 PDF 改用页面图像识别页码。

## 升级说明

书签层级规则有更新。以前处理过的书重新运行，或勾选“续跑”，都会按新规则重新生成书签；来源和输出位置不变且原件未被覆盖时，会复用已缓存的识别结果，不再重复调用 DeepSeek。若曾直接覆盖原 PDF，默认的“核对并修正”会发现旧书签层级不一致并替换。

正式识别会把所需页面的图片发送到 DeepSeek，可能产生 API 费用；预览只在本机完成。当前构建未做代码签名，Windows 可能显示来源提示。
