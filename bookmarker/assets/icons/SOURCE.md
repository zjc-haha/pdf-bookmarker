# Tabler Icons assets

These icons come from the official [Tabler Icons v3.48.0 release](https://github.com/tabler/tabler-icons/releases/tag/v3.48.0), commit `0239805680a36bab4e1070529b6744924402d804`. The original files are from [`icons/outline`](https://github.com/tabler/tabler-icons/tree/v3.48.0/icons/outline). Each `.svg` here is an unchanged copy of its source file. Each matching `.png` is a 96 × 96 transparent, white alpha mask rendered from that SVG for offline use in the Tkinter application. PNG generation replaces only `currentColor` with white in memory before rendering; the stored SVGs retain `currentColor`.
